# 论文缺陷分析与改进计划

## 一、识别的主要缺陷

### 1. 策略选择过于简化（硬切换问题）
**问题描述**: 原方法直接选择最大RMP对应的单一策略，缺乏平滑过渡
```python
# 原代码问题
ind=np.where(nn==rr)[0]  # 只选最大值
return ind[0],rr
```
**改进方案**: 采用加权融合策略，根据各维度RMP的相对大小自适应加权

### 2. 阈值参数经验性过强
**问题描述**: 低频过滤阈值 `ke = max(int((j+1)/mmm/8), 1)` 中常数8缺乏理论依据
**改进方案**: 实现自适应阈值，根据数据分布动态调整

### 3. 缺乏统计显著性检验
**问题描述**: 仅报告准确率，无p-value或置信区间
**改进方案**: 增加统计检验和多次运行稳定性分析

### 4. 评估指标单一
**问题描述**: 仅使用Top-K准确率
**改进方案**: 增加MRR、NDCG、覆盖率等指标

### 5. 冷启动问题
**问题描述**: 新用户或稀疏数据处理过于简单
**改进方案**: 引入全局流行度作为平滑项

---

## 二、具体改进计划

### 改进1: 加权融合RMP策略 (Weighted RMP)

**核心思想**: 不再硬选择单一策略，而是根据各维度RMP值进行 softmax 加权

**数学公式**:
```
w_i = exp(RMP_i) / sum(exp(RMP_j))
P_final = sum(w_i * P_i)
```

**实现位置**: `improved markov/weighted_rmp_model.py`

### 改进2: 自适应阈值 (Adaptive Threshold)

**核心思想**: 根据转移矩阵的稀疏程度动态调整过滤阈值

**数学公式**:
```
ke = percentile(transition_counts, alpha)
其中 alpha 根据数据稀疏度自适应选择
```

### 改进3: 平滑冷启动 (Smooth Cold Start)

**核心思想**: 当用户历史不足时，融入全局位置流行度

**数学公式**:
```
P_blend = beta * P_user + (1-beta) * P_global
其中 beta = min(1.0, history_length / threshold)
```

### 改进4: 综合评估指标

新增指标:
- **MRR** (Mean Reciprocal Rank)
- **NDCG@K** (Normalized Discounted Cumulative Gain)
- **Coverage** (预测位置覆盖度)
- **Diversity** (预测列表多样性)
