**日期**: 2026-03-20

## 方法介绍

### 1. Base Markov (基线)
基础一阶马尔可夫模型，仅使用 OD (Origin-Destination) 转移概率。

### 2. RMP (原论文方法)
Refined Maximum Predictability，根据最大可预测性选择单一最优策略。

### 3. Weighted RMP (改进1)
**核心改进**: Softmax加权融合多维度策略，而非硬选择单一策略。

**关键特性**:
- 6种策略的softmax加权融合
- 平滑冷启动机制
- 综合评估指标 (MRR, NDCG)

### 4. ADF (新方法 - Attention-based Dynamic Fusion)
**核心创新**: 基于注意力机制的动态融合

**关键特性**:
- 上下文感知注意力权重计算
- 多头注意力融合 (3 heads)
- 时间注意力机制 (近期历史加权)
- 自适应门控平衡个性化与全局趋势

## 方法分析

### 为什么 Weighted RMP 效果更好？

**原RMP的问题**:
```python
# 硬选择单一策略
ind=np.where(nn==rr)[0]  # 只选最大值
return ind[0],rr
```
- 忽略了其他策略的有用信息
- 策略切换可能不稳定

**Weighted RMP 的改进**:
```python
# Softmax加权融合
weights = softmax(np.array([r_tod, r_td, r_od, r_d, r_tod2, r_td2]))
p_fused = sum(w_i * p_i)  # 加权融合
```
- 充分利用所有维度的信息
- 平滑的权重过渡，避免硬切换

### ADF 的优势

1. **上下文感知**: 根据当前时空上下文动态调整权重
2. **多头融合**: 从不同子空间捕获信息，类似Transformer
3. **时间注意力**: 近期行为对预测影响更大
4. **自适应门控**: 自动平衡个性化与全局趋势

---

## 结论

1. **改进验证成功**: Weighted RMP 和 ADF 均显著超越原方法
2. **软融合优于硬选择**: 加权融合策略比单一策略选择更有效
3. **注意力机制有效**: ADF的上下文感知注意力进一步提升性能
4. **综合指标更可靠**: MRR和NDCG提供了比Top-K更全面的评估

**最终排名**: ADF > Weighted RMP > RMP (Original) > Base Markov
