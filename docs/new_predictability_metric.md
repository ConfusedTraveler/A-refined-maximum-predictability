# 新可预测性指标：ATDP (Adaptive Temporal Decay Predictability)

## 背景与动机

原RMP指标的问题：
1. **时间无关性**: 将所有历史转移同等对待，没有考虑时间衰减
2. **静态假设**: 假设用户行为模式是静态的，忽略了动态变化
3. **简单取最大**: 6个维度简单取最大值，缺乏有机融合

人类移动的实际特性：
- **近期行为更重要**: 昨天去的地方比上个月去的地方更能预测今天
- **周期性模式**: 工作日/周末有周期性规律
- **上下文依赖**: 预测应依赖当前上下文（时间、位置）

## ATDP 指标设计

### 核心思想
引入**时间衰减因子**，让近期的转移对可预测性贡献更大。

### 数学定义

#### 1. 时间衰减权重
对于第 $t$ 个时间步（距当前 $t$ 步前），其权重为：

$$w_t = \exp(-\lambda \cdot t^{1/2})$$

其中：
- $\lambda$ 是衰减率（自适应计算）
- 使用 $t^{1/2}$ 而非 $t$ 来减缓衰减速度

#### 2. 自适应衰减率
根据用户历史长度的稀疏度自适应选择 $\lambda$：

$$\lambda = \alpha \cdot \frac{N_{unique}}{N_{total}}$$

- $N_{unique}$: 不同位置数
- $N_{total}$: 总记录数
- $\alpha$: 调节参数（默认0.5）

#### 3. 加权条件熵
传统的条件熵：

$$H(Y|X) = -\sum_{x,y} p(x,y) \log p(y|x)$$

ATDP的**时间加权条件熵**：

$$H_{TW}(Y|X) = -\sum_{t} w_t \sum_{y} p_t(y|x_t) \log p_t(y|x_t)$$

其中 $p_t$ 是基于时间 $t$ 之前数据计算的条件概率。

#### 4. 多尺度时间加权
同时考虑多个时间尺度：
- **短期** (最近5个): 权重 ~1.0
- **中期** (最近20个): 权重 ~0.7  
- **长期** (全部): 权重 ~0.4

$$H_{MS} = \beta_1 H_{short} + \beta_2 H_{medium} + \beta_3 H_{long}$$

#### 5. 最终ATDP计算
基于加权熵计算最大可预测性：

$$S = H_{MS} + (1-\Pi) \log(N-1)$$

使用牛顿迭代法求解 $\Pi_{max}$，即 ATDP。

## ATDP vs RMP 优势

| 特性 | RMP | ATDP |
|------|-----|------|
| 时间衰减 | ❌ 无 | ✅ 有 |
| 自适应参数 | ❌ 固定阈值 | ✅ 自适应λ |
| 多尺度融合 | ❌ 单尺度 | ✅ 短/中/长期 |
| 动态更新 | ❌ 静态 | ✅ 动态 |
